  Figma typings load only through `src/figma-env.d.ts`.

## Known phase-1 gaps (accepted, documented)

- Rotated nodes are flattened (`ROTATED-NODE`).
- Angular/diamond gradients skipped (`UNSUPPORTED-FILL`).
- Only the first visible fill / first shadow is emitted (reports the rest).
- No `@2x`/`@3x` density asset split (PNGs keep the stored Figma resolution).
- Library (published) text style ids are not dereferenced, only on-node styles.
- Design-system tokens are local-document values: font families classify by
  name hints (no font bundling), text decorations/case are not represented,
  gradient paint styles keep only their first stop, and composed colors whose
  parts are variables are skipped (all documented + diagnosed).

Absolute-positioned children ("ignore auto-layout") are supported as of rev. 2
(wrapper `Box` decomposition; see [generation.md](generation.md)). The full
contract and all diagnostic codes live in
[limitations.md](limitations.md).
